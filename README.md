# Glucocorticoid_Transcriptomics-sc-RNA-seq-
Single-Cell Dissection of Glucocorticoid Response Heterogeneity: Identifying Transcriptional Programs Associated With Hormone Responsiveness.

## Project overview
This project uses the public GEO dataset GSE141834, titled "Transcriptional Heterogeneity within the Glucocorticoid Response", to explore how gene expression changes across a dexamethasone time course in A1-2 human breast cancer cells and how the response varies from cell to cell.

## The notebook demonstrates a practical Python/Scanpy workflow:
dataset retrieval, raw-count inspection, quality control, normalization,
highly variable gene selection, PCA/UMAP, time-course summaries,
exploratory differential expression, pathway enrichment, glucocorticoid
response signature scoring, and response-score heterogeneity analysis.
Project type: computational single-cell transcriptomics portfolio project.
Primary tools: Python, pandas, NumPy, SciPy, AnnData, Scanpy,
GSEApy, Matplotlib/Seaborn, Google Colab, Google Drive.


## Questions explored
1. How does expression of selected genes change across the control
and dexamethasone time points?
2. Do selected glucocorticoid-response genes show early, sustained,
or later expression patterns?
3. How heterogeneous are expression levels across individual cells
at the same time point?
4. How does the relative glucocorticoid-response signature score
vary across the time course?
5. Which genes and functional annotations recur in exploratory
comparisons of high- and low-score cells?

## Dataset and design
•  GEO accession: GSE141834
•  Study: Transcriptional Heterogeneity within the Glucocorticoid
Response
•  System: A1-2 human breast cancer cells exposed to
dexamethasone (Dex; 100 nM in the study design)
•  Time points represented in the notebook: control/0 h, 1 h, 2 h,
4 h, 8 h, and 18 h
•  Data type: single-cell gene-expression count matrix
Sample prefixes are mapped to treatment times in the notebook. The
mapping should be checked against GEO metadata before reusing or
extending the analysis.


## Workflow
1. Environment and data access — mount Drive, install pinned
package versions, retrieve GEO metadata, and download the raw
count matrix.
2. Input validation — inspect the compressed matrix, cell identifiers,
missing values, negative values, and count data types.
3. Quality control — calculate detected genes, total counts, and
mitochondrial percentage; inspect their distributions; apply
provisional cell-level thresholds.
4. AnnData and normalization — store the matrix in cells-by-genes
format, preserve raw counts, normalize each cell to a target library
size, and log-transform.
5. Feature selection and embedding — identify highly variable
genes, scale the HVG subset, run PCA, construct a neighbor
graph, and calculate UMAP.
6. Time-course exploration — map sample prefixes to time points,
compare mean expression, and visualize selected gene
trajectories and single-cell distributions.
7. Exploratory differential expression and enrichment —
compare treatment time points with control and query pathway
annotations for selected gene lists.
8. Signature scoring and heterogeneity — score cells using a
selected glucocorticoid-response signature, examine score
distributions and gene associations, define within-time quantile
groups, and prioritize recurring candidate genes.
9. Persistence and reproducibility — save results and AnnData
objects to Google Drive, verify expected files, and create figures
for the portfolio.


## Main observations recorded in the notebook
•  The glucocorticoid-response signature score increases across the
time course and remains elevated at later time points in the
descriptive summaries.
•  Selected genes show different temporal patterns rather than a
single uniform response. For example, FKBP5 is examined as a
sustained response marker, while NFKBIA is examined for a more
early response pattern.
•  Individual-cell plots show that gene expression and response
score values vary among cells within the same time category.
•  Translation/ribosome and mitochondrial respiration-related
annotations recur in some down-associated gene lists. These are
enrichment observations and may reflect overlapping genes
among related terms.
•  High- and low-score comparisons identify candidate genes for
further investigation, but the score-defined groups and cell-level
tests make these results exploratory.
Exact numerical results should be quoted from the saved output tables
and figures generated by the notebook rather than copied from this
overview.

## Important limitations
- Limited biological replication and pseudoreplication
Cells are nested within samples. Treating every cell as an independent
replicate in a Wilcoxon test can underestimate uncertainty and inflate
statistical significance. The notebook itself labels cell-level differential
expression as exploratory. For stronger inference, use sample-aware
pseudobulk or mixed-model approaches if the available sample structure
supports them.
- QC choices
The notebook uses thresholds based on detected genes, total counts,
and mitochondrial percentage. These are practical filters, not universal
standards. Report the exact thresholds and number of retained cells.
- UMAP interpretation
UMAP is a visualization of a selected expression representation and
parameterization. It does not prove that clusters are discrete cell types
or that a treatment caused a particular separation.
- Response-score interpretation
The signature score is a relative expression score based on selected
genes, not a direct biochemical measurement of glucocorticoid-receptor
activity. Negative scores do not imply negative biological activity.
- Quantile groups and circularity
High/intermediate/low groups are defined from the score distribution
within each time point. They are not validated biological responder
classes. Differential expression between score-defined groups can be
partly circular because signature genes contribute to the score.
- Enrichment interpretation
Enrichment identifies annotations over-represented in a gene list; it does
not demonstrate pathway activation, suppression, or causality. Disease
labelled pathway terms should not be interpreted as evidence that
dexamethasone causes the named diseases.
